# Home Appliance Service - Customer Portal

## Overview

The Customer Portal is a React-based frontend application that allows customers to browse home appliance services, book service appointments, track booking status, view assigned technicians, and view payment details after service completion.

The application communicates with the Node.js/Express backend through REST APIs and provides a responsive user experience using Bootstrap.

---

## Features

### Authentication
- Customer Registration
- Customer Login
- JWT Authentication
- Protected Routes

### Service Management
- View Available Services
- Service Details
- Service Categories

### Booking Management
- Book Service
- View Booking History
- Track Booking Status

### Profile Management
- View Profile
- Update Customer Information

### Payment Tracking
- View Service Charges
- View Final Payment Amount
