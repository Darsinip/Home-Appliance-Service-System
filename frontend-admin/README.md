# Home Appliance Service - Admin Portal

## Overview

The Admin Portal is a centralized dashboard that enables administrators to manage services, technicians, bookings, customer requests, and billing operations.

The portal provides complete control over service operations and customer management.

---

## Features

### Dashboard
- Total Customers
- Total Services
- Total Technicians
- Total Bookings
- Revenue Tracking

### Service Management
- Add Service
- Edit Service
- Delete Service
- View Services

### Technician Management
- Add Technician
- Edit Technician
- Delete Technician
- Assign Technicians

### Booking Management
- View Customer Bookings
- Assign Technician
- Update Booking Status
- Complete Service

### Billing
- Generate Service Charges
- Update Final Payment Amount
- View Revenue Data
